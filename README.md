## 📊 O que eu faço

### 🏗️ Sistemas de gestão full-stack
Módulos completos, do modelo de dados à tela — financeiro (títulos, cobranças, recorrências, fluxo de caixa), matrícula online, planejamento tributário, formulários com geração de PDF — em **Java 21 / Spring Boot 4 + React/TypeScript** e em **Laravel 11 + Vue 3**.

### 🔗 Integrações de API e sincronização de dados
Jobs em fila com scheduler e cache em Redis para consolidar dados de sistemas externos em dashboards (DRE, contas a receber/pagar, estoque, projeções).

### ⚙️ Código que aguenta produção
Lock distribuído em jobs agendados para rodar com várias réplicas, credenciais cifradas em repouso, migrations versionadas com Flyway, testes de integração com Testcontainers e servidor SMTP/IMAP em processo, esteira CI/CD com Docker Hub + Portainer.

### 📈 Dados e observabilidade
Pipelines de API → PostgreSQL orquestrados em n8n e dashboards Grafana gerados por código.
